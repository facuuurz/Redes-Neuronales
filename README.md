# Neural Networks — Sentiment Classification (Keras MLP)
Binary sentiment classification on the
[rotten_tomatoes](https://huggingface.co/datasets/cornell-movie-review-data/rotten_tomatoes)
dataset (movie reviews, 50% positive / 50% negative).
## Requirements
```
pip install tensorflow-cpu datasets scikit-learn matplotlib pandas
```

The numbers, tables, and observations from every experiment are

50/50 dataset, chance = 50%).
## Design
- **Vectorization**: TF-IDF with 10,000 features (unigrams + bigrams). A dense
  MLP needs fixed-size input; TF-IDF is the classic choice for text.
- **Base model**: `Dense(64) → Dropout(0.5) → Dense(32) → Dropout(0.5) → Dense(1, sigmoid)`,
  Adam lr=1e-3, binary crossentropy, 15 epochs, batch 64.
- **Overfitting**: a large network (512-256-128) without dropout, 40 epochs → the
  val_loss goes up while the train_loss drops to ~0.
- **Experiments**: learning rate, layer size, dropout, and batch size,
  changing one at a time over the base config.
- **Metric**: the dataset is balanced → accuracy is appropriate; F1, precision,
  and recall are also reported.
